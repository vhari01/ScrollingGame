# 🧺 Egg Catcher Game – Java OOP Project

This project was a Java-based scrolling game developed using Object-Oriented Programming principles. The goal of the game was simple: **catch falling eggs** to score points and **avoid falling bombs**, which deducted points. The game was built with a clean and interactive interface using **Java Swing** for the GUI.

## 🎮 Game Overview

- Players controlled a **basket** that moved horizontally to catch items falling from the top of the screen.
- **Eggs** awarded **+1 point** when caught.
- **Bombs** deducted **2 points** from the score.
- The game got progressively challenging as item speed increased over time.

## 🔧 Technologies Used

- **Java (OOP)**: Core game logic, collision detection, object hierarchy (e.g., Basket, Egg, Bomb)
- **Java Swing**: Used to add background images, draw game elements, and create an interactive GUI

## 🎯 Key Features

- Dynamic object creation and movement using timers
- Real-time score tracking and updates
- Visual feedback with custom graphics for basket, eggs, bombs, and background
- Smooth user controls (arrow keys or A/D for movement)

## 📁 Structure

- `Game.java`: Launched the game window
- `GamePanel.java`: Handled game rendering and logic updates

## 🧠 Learning Outcome

This project helped reinforce concepts of:
- Object-oriented design
- GUI development with Java Swing
- Real-time game loops and event handling
